# Review Checklist

Use this checklist to review a completed UI change. It aggregates the product,
engineering, accessibility, and responsive checks without duplicating them.

## Scope and correctness

- [ ] The implemented behavior matches the request and current product capabilities.
- [ ] Applicable product guidance, service boundaries, compatibility, state
  restoration, and failure recovery were checked.
- [ ] The change introduces no unrelated redesign, dependency, or feature scope.

## Evidence and decision

- [ ] Applicable checklists and tests were completed; material visual changes
  include runtime or screenshot evidence.
- [ ] Findings cite concrete files, states, dimensions, or reproduction steps.
- [ ] Limitations and unverified claims are stated, followed by an evidence-based
  `Accept`, `Needs Refinement`, or `Reject` decision.
