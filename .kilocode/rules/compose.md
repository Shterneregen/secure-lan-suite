# Compose UI Rule

Compose code must express product structure, not legacy parity.

Required:

- Separate product state from composables.
- Use semantic components.
- Keep chat visually dominant.
- Keep context panel contextual.
- Preserve accessibility and keyboard focus.

Forbidden:

- Large monolithic composables.
- Random local colors and dimensions.
- Recreating JavaFX panels.
- Showing technical state in normal screens.
