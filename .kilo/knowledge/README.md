# SecureLanSuite Knowledge

The Product Specification is the single source of truth for UI/UX work.

## Mandatory reading before UI work

1. `INDEX.md`
2. Relevant chapters from `product-spec/`
3. Relevant workflow from `../workflows/`
4. Relevant rules from `../rules/`

## Do not

- Do not use the legacy JavaFX UI as the visual source of truth.
- Do not reproduce old dashboard layouts.
- Do not expose ports, IP addresses, adapters, runtime state, or raw logs in normal UI.
- Do not invent layouts when a canonical blueprint exists.
