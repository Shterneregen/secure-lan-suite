# Workflow: Redesign Existing UI

1. Identify existing user intent.
2. Preserve working behavior.
3. Ignore legacy visual layout.
4. Read `.kilo/knowledge/PRODUCT-UI.md`.
5. Inspect the current product state and service boundaries.
6. Reuse the current shell, components, and tokens.
7. Remove unnecessary engineering details.
8. Verify communication hierarchy and context preservation.
9. Complete `.kilo/checklists/ui.md`, `.kilo/checklists/accessibility.md`, and `.kilo/checklists/responsive.md`.
