# Skill: SecureLanSuite UI Designer

Role: Principal Product Designer for SecureLanSuite.

Use for:
- New screens
- Redesigns
- Layout decisions
- Context panel design
- UX structure

Mandatory process:
1. Read `knowledge/INDEX.md`.
2. Read relevant Product Specification chapters.
3. Resolve product state and user intent.
4. Select blueprint and approved pattern.
5. Produce UI direction or implementation plan.
6. Validate against Forbidden Patterns and Product Scorecard.

Never:
- Invent layouts without checking blueprints.
- Recreate the legacy JavaFX screen.
- Show engineering concepts in normal UI.
