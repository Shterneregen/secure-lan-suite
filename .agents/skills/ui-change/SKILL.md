# UI Change

Apply `securelan-ui-design` when the task requires a product, flow, layout, or
surface decision, then apply `compose-engineering` to implement it. Use the UI
checklist under `docs/quality/` and any applicable accessibility or responsive
checklist. Verify the changed behavior and report evidence, limitations, and
material tradeoffs.
