# Feature Change

1. Establish the requested outcome and current behavior from code and tests.
2. Inspect affected modules, dependencies, compatibility, and documentation.
3. Read the applicable domain skill and product guidance.
4. Implement the complete requested behavior, including realistic failure and
   recovery paths.
5. Add or update focused tests when they provide meaningful verification.
6. Update public documentation when behavior, compatibility, architecture,
   packaging, or supported platforms change.
7. Run the narrowest relevant checks and report evidence, limitations, and
   tradeoffs.
